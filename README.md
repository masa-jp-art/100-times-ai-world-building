# 100 Times AI World Building

## Overview
This project allows users to generate intricate worlds through AI, supporting both cloud and local execution.

## Cloud Version
- **Description**: The cloud version leverages powerful servers to generate extensive worlds without requiring local resources.
- **Usage**: Simply access the web interface, log in, and start generating worlds.
- **Requirements**: An internet connection and a valid user account.

## Local Version
- **Description**: The local version can be run directly on your machine, providing flexibility and speed for developers.
- **Installation**: Follow the setup instructions provided in the INSTALL.md file.
- **Requirements**: A compatible operating system and necessary dependencies installed on your machine.

## Getting Started
1. Clone the repository.
2. Follow the instructions in INSTALL.md for the local version.
3. For cloud usage, ensure you have an account.
